Website › Configuration › **Page content** → the **Category in the directory**
field above the tabs.

Leaving it empty lists the shop without a category. `/mi-comercio` keeps
working and both write through the same method, so the two can never disagree.

In **Settings › Companies** the search box also matches the heading of the
microsite (`microsite_name`), next to the legal name, the trade name, the VAT
and the registry number.
