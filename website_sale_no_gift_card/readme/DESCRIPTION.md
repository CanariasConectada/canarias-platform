Odoo's shop offers every customer a "Coupon, Gift card, Promo-code?" box on
the cart, the checkout and the order confirmation. On this platform nobody
issues coupons or gift cards, so the box only invited shoppers to look for a
code that does not exist — and it appeared on all 200-odd shops without
their owners asking for it.

This module switches off that whole surface: the promo row under the totals,
the gift-card field and its placeholder, the "gift card used" line in the
cart summary and the gift-card block on the confirmation page, plus the link
that carries the same words in the mobile cart drawer.

It removes the *platform's* gift-card machinery, not a merchant's catalogue:
a shop that sells its own gift card as a product keeps selling it.
