# Company Certification

Parameterizable company certification seals (Silver Economy,
Sustainability, ...) built on the native Survey app.

Fusion of the legacy `silver_economy` and `sustainability` modules: each
vertical is now a `certification.type` record (groups, survey, thresholds,
timing, badge), so adding a vertical requires zero code. Visibility is
gated per vertical group — plain internal users see nothing.

See the `readme/` fragments for description, usage, history and roadmap.

Directory badges and filters for `website_directory` live in the
`website_directory_company_certification` bridge module (auto-installed).
