# Zone Fix

**Versión:** 1.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Fixes y parches para el funcionamiento de zonas y productos en microsites.

## Descripción

Módulo de correcciones para el sistema de zonas. Gestiona redirecciones de
productos, publicación de productos por website, y fixes del mixin de website
para el modelo multi-tenant de zonas comerciales.

## Dependencias

- `base`, `website`, `website_sale` (Odoo core)

## Notas

El prefijo `zzz_` garantiza que este módulo se cargue al final, después de
todos los demás módulos de la plataforma.
