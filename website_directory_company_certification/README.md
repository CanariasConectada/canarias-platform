# Website Directory - Company Certification

Auto-installed bridge: certification badges on directory entries and a
seal filter in the directory sidebar, built exclusively on the
`website_directory` extension hooks (`_get_extra_filter_domain`,
`_get_extra_pager_args`, `directory_sidebar_extra`).
