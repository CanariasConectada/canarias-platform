## 19.0.1.2.0 (2026-09-16)

* "Shop categories" is the only screen of the shop's categories: the "Own
  categories" button and its list are gone. Own rows are renamed in the
  "Name" column and deleted with a trash button on the row; shared rows are
  neither. "New own category" adds the category as a new row directly.

## 19.0.1.1.0 (2026-09-16)

* "Shop categories" lists every category of the shop at once: the shop's
  own categories and the shared ones its products use, with a "Type"
  column, own first. Rows are created when the screen opens and when an own
  category is created; a row is only removed when its category is no longer
  used and it carries no image and no label.

## 19.0.1.0.1 (2026-09-16)

* The shared "eCommerce Categories" screen is no longer offered to merchants:
  saving there raised an access error. They use "Shop categories".
