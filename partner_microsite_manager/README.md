# Partner Microsite Manager

**Versión:** 1.3.9 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Gestión de microsites desde el formulario de contacto de la compañía.

## Descripción

Añade una pestaña "Microsite" en `res.partner` para gestionar el contenido del
website asociado a la compañía: logo, descripción, redes sociales, horario,
productos destacados. Sincroniza bidireccionalmente los datos entre `res.partner`,
`res.company` y `website`.

## Dependencias

- `base`, `website` (Odoo core)
- `theme_corporate_multi` (canarias-website)
