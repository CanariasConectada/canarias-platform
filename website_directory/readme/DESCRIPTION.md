Public business directory for the Canarias Conectada marketplace, served at
`/comercio`.

Each participating company gets a directory entry
(`website.directory.entry`) that is kept in sync automatically from the
company itself: name, contact data, logo, business category and published
state. The public page offers:

* visual cards (grid) or a compact list, with the company logo,
* a cascading category filter (up to three levels) based on the OCA
  `res.company.category` hierarchy, including all descendants of the
  selected category,
* an asynchronous text search on the entry and partner names,
* configurable page size and AJAX pagination,
* a fair, deterministic daily shuffle of the businesses (cookie-seeded), so
  no company is always listed first.
