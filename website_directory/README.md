# Website Directory - Canarias Conectada

**Versión:** 19.0.4.6.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Directorio de empresas con filtros por zona y categoría para Canarias Conectada.

## Descripción

Muestra en `/directorio` un listado de empresas/microsites con cards visuales,
filtros por zona comercial y categoría jerárquica (tres niveles), búsqueda
asíncrona AJAX, vistas grid y lista, y paginación configurable (12/21/48).

## Dependencias

- `website` (Odoo core)
- `business_category_hierarchy` (canarias-platform)

## Uso

Acceder a `/directorio` en cualquiera de los portales zonales para ver
el directorio filtrable de comercios.
