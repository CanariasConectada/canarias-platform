Settings ▸ Users ▸ a user ▸ Extra rights ▸ tick **Comercios**.

A user created from now on already has it. To stop that, remove *Comercios*
from the implied groups of *Default access for new users* (Settings ▸
Technical ▸ Groups).

To give one merchant a personal dashboard, tick **Merchant dashboard** on
the same form: a "My Dashboard" app appears for that user, where any view
can be pinned through *Favorites ▸ Add to dashboard*. Nobody gets it by
default.
