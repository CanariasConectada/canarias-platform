Settings ▸ Users ▸ a user ▸ Extra rights ▸ tick **Comercios**.

A user created from now on already has it. To stop that, remove *Comercios*
from the implied groups of *Default access for new users* (Settings ▸
Technical ▸ Groups).

To give one merchant a personal dashboard, tick **Merchant dashboard** on
the same form: a "My Dashboard" app appears for that user, where any view
can be pinned through *Favorites ▸ Add to dashboard*. Nobody gets it by
default.

Purchase, Inventory and Invoicing are not part of *Comercios*. To enable
them for one merchant, on the same user form (Ajustes ▸ Usuarios y
compañías ▸ Usuarios ▸ the merchant):

1. **Compra**: choose *Usuario*.
2. **Inventario**: choose *Usuario*.
3. **Facturación / Contabilidad**: choose *Facturación*.
4. Save. The apps appear on the merchant's next page load.

The link tracker is hidden for everybody but administrators. To enable it
for one merchant, tick **Rastreador de enlaces** (*Link Tracker*) under
*Permisos adicionales* on the same form and save.
