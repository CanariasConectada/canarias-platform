# Moderation: Forbidden Words

**Version:** 19.0.1.0.0 | **License:** AGPL-3 | **Author:** Canarias Conectada

One administrator-managed list of forbidden words and expressions, shared
by every moderated text of the platform (merchant reviews, local content
comments...). Accent- and case-insensitive whole-word matching, multi-word
entries, seeded Spanish list.

See the `readme/` fragments for the full description, configuration, usage
and history.

## Dependencies

- `base` (Odoo core)
