# Microsite Zones

**Versión:** 1.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Gestión de zonas comerciales y microsites para la plataforma Canarias Conectada.

## Descripción

Módulo central de la plataforma. Extiende `website` y `res.company` para soportar
el modelo multi-tenant de zonas comerciales: cada empresa local tiene su propio
microsite, y los microsites se agrupan en zonas geográficas. Gestiona categorías
de producto por empresa y la estructura de menús de cada microsite.

## Dependencias

- `base`, `website`, `website_sale` (Odoo core)
