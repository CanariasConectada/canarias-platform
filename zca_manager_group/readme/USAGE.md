To make someone the manager of a zone, as an administrator:

1. Settings ▸ Users ▸ New.
2. *Company* and *Allowed companies*: the zone company only (for example
   "Zona Comercial Guanarteme"). Nothing else in *Allowed companies*.
3. Extra rights ▸ tick **ZCA Manager**. Leave *Comercios* unticked.
4. Save and send the invitation.

The user then sees Discuss, Calendar, Contacts (with a *Companies* entry
listing the shops of their zone), Events, Email Marketing and Website, and
is a member of the zone's chat channel.

Three zones, three users: one per zone company. The same person can only
manage one zone, because the zone is the session company.

To send a mailing to the members of the zone, create it on *Contacts* and
filter by *Commercial Zone* (the zone company): the recipients the manager
can see are exactly the zone's.
