# Microsite Menu Manager

**Versión:** 1.0.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Gestor centralizado de menús para microsites multi-website.

## Descripción

Centraliza la creación y sincronización de menús de website según el tipo de site:
- **Canarias Conectada** (portal padre): menú principal con directorio y zonas
- **Zonas Comerciales** (Guanarteme, Tamaraceite, Lomo Los Frailes): menú zonal
- **Microsites de empresa**: menú de comercio individual

Evita duplicados y mantiene consistencia entre todos los sitios.

## Dependencias

- `website` (Odoo core)
- `website_directory` (canarias-platform)
- `partner_reviews` (canarias-platform)
- `microsite_zones` (canarias-platform)
- `event` (Odoo core)
