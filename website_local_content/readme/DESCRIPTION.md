Parameterizable public galleries of local content.

This module fuses the legacy `memoria_viva` (Living Memory) and
`lugares_interes` (Places of Interest) modules, which were clones of each
other, into a single engine where each vertical is a **content type data
record**: category / subcategory / item hierarchy, anonymous likes and the
public website pages are all parameterized by the type. Adding a third
vertical requires zero code.
