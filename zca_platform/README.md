# ZCA Platform

**Versión:** 19.0.1.3.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Plataforma de Zonas Comerciales Abiertas (ZCA).

## Descripción

Módulo core de la plataforma ZCA. Gestiona múltiples comercios como empresas
independientes con directorio público, microsites por comercio, filtros avanzados
con AJAX, y modelos de seguridad (`zca_security`) para el acceso por roles.

## Dependencias

- `website`, `website_sale`, `sale`, `stock`, `account`, `purchase`, `crm`, `project`, `hr` (Odoo core)
