# Microsite Company Switch

**Versión:** 19.0.1.0.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Sincroniza la cookie de compañía y gestiona el aislamiento entre microsites.

## Descripción

Gestiona el cambio de contexto de compañía en el frontend cuando un usuario
navega entre microsites. Sincroniza la cookie de compañía activa con el
website visitado para garantizar el correcto aislamiento de datos por empresa.

## Dependencias

- `base` (Odoo core)
- `website` (Odoo core)
