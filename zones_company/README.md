# Zonas para Empresas

**Versión:** 19.0.1.7.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Gestión de zonas geográficas para organizar empresas en la plataforma.

## Descripción

Módulo base de la plataforma. Define el modelo `zone` y lo vincula a `res.company`.
Permite crear y gestionar zonas comerciales (Guanarteme, Tamaraceite, etc.),
asignar empresas a zonas, y usar las zonas como criterio de filtrado y seguridad.

## Dependencias

- `base`, `sale_stock` (Odoo core)

## Configuración

Ajustes > Zonas Comerciales para crear y gestionar las zonas.
