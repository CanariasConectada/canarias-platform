# Business Category Hierarchy

**Versión:** 19.0.1.3.0 | **Licencia:** AGPL-3 | **Autor:** MikeColangelo

Gestión jerárquica de categorías de comercio para segmentación de empresas
en el directorio de Canarias Conectada.

## Descripción

Implementa un sistema de categorías de tres niveles (principal, secundaria, terciaria)
para clasificar los comercios locales. Las categorías se asignan a `res.company`
y se usan como filtros en el directorio web.

## Dependencias

- `contacts` (Odoo core)
- `zones_company` (canarias-platform)

## Configuración

Administración > Categorías de Negocio para gestionar el árbol de categorías.
