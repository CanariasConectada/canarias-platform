- Manage the tree in *Contacts > Configuration > Business Categories*.
- Assign categories to a company in the company form (*Settings > Companies*),
  in the **Business Categories** tags field; new categories can be created on
  the fly by typing a name.
- Bulk-import categories from a pasted text list in
  *Contacts > Configuration > Import Categories*. Lines starting with exactly
  two spaces become root categories; the following unindented lines become
  their children. Markdown links (`[Name](url)`) are accepted, the URL is
  ignored. Existing categories are matched by name and never duplicated.
