# Zones Toolbar Fix

**Versión:** 1.0.0 | **Licencia:** LGPL-3 | **Autor:** MikeColangelo

Agrega el toolbar de contador y controles a las páginas de zonas comerciales.

## Descripción

Corrige la ausencia del toolbar (contador de resultados, toggles de vista,
selector de paginación) en las páginas de listado de zonas comerciales.
Extiende los templates de `microsite_zones` para incluir los controles estándar.

## Dependencias

- `website`, `website_sale` (Odoo core)
- `microsite_zones` (canarias-platform)
